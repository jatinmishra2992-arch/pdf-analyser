How it works

  1. Your PDF is split into parts of about ten pages, so long files don't time out.
  2. Each part is read by the Gemini AI model, which writes notes in the same order as the original.
  3. The parts are joined into one set of notes, with a marker wherever a diagram appears.

Good to know

  • The first visit can take about a minute, because the free server sleeps when nobody is using it.
  • Long PDFs can take a few minutes. The page shows which part is being read.
  • Your PDF is sent to Google's Gemini API to be read, so please don't upload private documents.
  • Diagrams are marked in the notes, but they are not copied into them yet.
